# Drishti AI — Supabase Database Schema & Data Dictionary

## 1. Schema Inventory & Domain Summary

The Drishti AI database schema contains **22 entities** (1 built-in `auth.users` identity table and 21 application domain tables) and **8 Remote Procedure Calls (RPCs)** deployed and verified on PostgreSQL 15.

```text
+---------------------------------------------------------------------------------+
|                                 DOMAIN ENTITY MAP                               |
+---------------------------------------------------------------------------------+
| 1. Identity & Pairing      | profiles, parent_child_relationships, pairing_codes |
|                            | pairing_attempt_tracker                            |
| 2. Preferences & Safety    | user_settings, navigation_preferences, saved_places |
|                            | emergency_contacts                                 |
| 3. Emergency & Telemetry   | emergency_sessions, emergency_telemetry,           |
|                            | device_live_status                                 |
| 4. Voice Commands          | voice_commands, voice_command_phrases,              |

+---------------------------------------------------------------------------------+
```

## 2. Table-by-Table Data Dictionary

### 2.1 Identity, Pairing & Access Control

#### `public.profiles`
* **Description:** Extends `auth.users` with user roles, full display names, emergency numbers, and avatar references.
* **Columns:**
  * `id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE`
  * `role TEXT NOT NULL CHECK (role IN ('ward', 'parent'))`
  * `full_name TEXT NOT NULL`
  * `phone_number TEXT`
  * `avatar_url TEXT`
  * `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
  * `updated_at TIMESTAMPTZ NOT NULL DEFAULT now()`

#### `public.parent_child_relationships`
* **Description:** Manages linking between visually impaired wards and authorized parent/guardian accounts.
* **Columns:**
  * `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
  * `parent_id UUID NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE`
  * `child_id UUID NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE`
  * `status TEXT NOT NULL CHECK (status IN ('pending', 'approved', 'rejected', 'revoked'))`
  * `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
  * `updated_at TIMESTAMPTZ NOT NULL DEFAULT now()`
  * `UNIQUE(parent_id, child_id)`

#### `public.pairing_codes`
* **Description:** Stores active 6-character pairing codes generated by wards.
* **Columns:**
  * `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
  * `child_id UUID NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE`
  * `code_digest TEXT NOT NULL` — Cryptographic hash: `sha256(raw_code || salt)`
  * `salt TEXT NOT NULL`
  * `expires_at TIMESTAMPTZ NOT NULL`
  * `is_used BOOLEAN NOT NULL DEFAULT false`
  * `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`

#### `public.pairing_attempt_tracker`
* **Description:** Tracks failed pairing attempts to enforce rate limiting and prevent brute-force attacks.
* **Columns:**
  * `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
  * `parent_id UUID NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE`
  * `failed_attempts INT NOT NULL DEFAULT 0`
  * `locked_until TIMESTAMPTZ`
  * `last_attempt_at TIMESTAMPTZ NOT NULL DEFAULT now()`

### 2.2 Emergency Sessions & Real-Time Telemetry

#### `public.emergency_sessions`
* **Description:** Tracks the lifecycle of active and historical emergency SOS alerts.
* **Columns:**
  * `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
  * `user_id UUID NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE`
  * `status TEXT NOT NULL CHECK (status IN ('active', 'resolved', 'cancelled'))`
  * `trigger_type TEXT NOT NULL CHECK (trigger_type IN ('voice', 'button', 'crash', 'fall'))`
  * `started_at TIMESTAMPTZ NOT NULL DEFAULT now()`
  * `resolved_at TIMESTAMPTZ`
  * `resolved_by UUID REFERENCES public.profiles(id)`

#### `public.emergency_telemetry`
* **Description:** High-frequency time-series telemetry recorded during active emergency sessions.
* **Columns:**
  * `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
  * `session_id UUID NOT NULL REFERENCES public.emergency_sessions(id) ON DELETE CASCADE`
  * `latitude DOUBLE PRECISION NOT NULL`
  * `longitude DOUBLE PRECISION NOT NULL`
  * `accuracy_meters REAL`
  * `tof_distance_mm INT` — Smart cane obstacle distance
  * `battery_percent INT`
  * `captured_at TIMESTAMPTZ NOT NULL DEFAULT now()`

#### `public.device_live_status`
* **Description:** Singleton live status heartbeat for two-sided parent tracking.
* **Columns:**
  * `child_id UUID PRIMARY KEY REFERENCES public.profiles(id) ON DELETE CASCADE`
  * `latitude DOUBLE PRECISION`
  * `longitude DOUBLE PRECISION`
  * `accuracy_meters REAL`
  * `battery_percent INT`
  * `is_cane_connected BOOLEAN NOT NULL DEFAULT false`
  * `is_emergency_active BOOLEAN NOT NULL DEFAULT false`
  * `location_updated_at TIMESTAMPTZ`
  * `heartbeat_updated_at TIMESTAMPTZ NOT NULL DEFAULT now()`

### 2.3 User Preferences & Configuration

* **`public.user_settings`:** Key-value preferences for speech rate, TTS voice volume, haptic intensity, collision warning distances, and language preference (`en`, `hi`, `mr`).
* **`public.navigation_preferences`:** Avoidance options (avoid stairs, avoid construction), preferred transport mode (walking), and routing verbosity.
* **`public.emergency_contacts`:** Trusted phone numbers, relation labels, and SMS dispatch priority.
* **`public.saved_places`:** Labeled geographical points (Home, Work, Clinic) with latitude, longitude, and indoor arrival hints.

---

### 2.4 Indoor Home Mapping Domain

* **`public.home_maps`:** Architectural indoor map models linked to a ward.
* **`public.home_map_floors`:** Floor levels, zero-elevations, and floor plan dimensions.
* **`public.home_map_versions`:** Snapshot history for incremental room and furniture updates.
* **`public.home_map_review_requests`:** Requests dispatched to guardians to review newly scanned room layouts.
* **`public.home_map_review_events`:** Audit trail of guardian approvals or boundary corrections.

---

### 2.5 Voice Commands, Audit & Governance

* **`public.voice_commands`**, **`voice_command_phrases`**, **`voice_command_parameters`:** Configurable voice intent registry allowing cloud synchronization of custom vocabulary and aliases.
* **`public.incident_reports`:** In-app bug and accessibility friction reporting.
* **`public.user_consents`:** GDPR/DPDP compliant timestamped consent records (location, audio processing, telemetry sharing).
* **`public.security_audit_logs`:** Immutable audit log capturing pairing attempts, revocation events, and emergency sessions.

## 3. Remote Procedure Calls (RPCs / Stored Procedures)

| Stored Procedure (RPC) | Security Mode | Parameters | Description |
| :--- | :---: | :--- | :--- |
| `generate_pairing_code()` | `SECURITY DEFINER` | None (reads `auth.uid()`) | Generates 6-char alphanumeric code, hashes with salt, saves digest to `pairing_codes` |
| `submit_pairing_code()` | `SECURITY DEFINER` | `p_code TEXT` | Validates attempt limits, hashes code, matches digest, and inserts pending relationship |
| `respond_to_pairing_request()`| `SECURITY DEFINER` | `p_relationship_id UUID`, `p_action TEXT` | Allows ward to set status to `approved`, `rejected`, or `revoked` |
| `start_emergency_session()` | `SECURITY DEFINER` | `trigger_type`, `lat`, `lng`, `acc`, `tof`, `batt` | Creates session in `emergency_sessions`, writes telemetry, marks `device_live_status` |
| `update_emergency_telemetry()`| `SECURITY DEFINER` | `session_id`, `lat`, `lng`, `acc`, `tof`, `batt` | Appends new telemetry row; updates live status coordinates |
| `end_emergency_session()` | `SECURITY DEFINER` | `session_id` | Sets status to `resolved` and clears emergency flag |
| `submit_incident_report()` | `SECURITY DEFINER` | `category`, `description`, `device_info` | Persists user issue report and creates audit event |
| `record_user_consent()` | `SECURITY DEFINER` | `consent_type`, `granted` | Inserts or updates user consent record with timestamp |
